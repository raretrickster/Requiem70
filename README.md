# Telegram-бот ритуального агентства «Реквием»

Готовый Telegram webhook для Netlify Functions. Бот не требует отдельного сервера, постоянного процесса, базы данных или Google Sheets.

## Что делает бот

- `/start` — отправляет фотографию из портфолио и приветствие.
- Кнопка **Оставить заявку** — просит клиента одним сообщением описать задачу и оставить телефон. Ответ пересылается администратору.
- Кнопка **Контакты** — показывает телефон, адрес, сайт, MAX и Google Maps.
- `/admin` — назначает текущий личный чат администратором. Заявки будут приходить сюда.
- `/myid` — показывает Telegram chat ID для диагностики.
- `/cancel` — отменяет текущий сценарий.
- `/resetadmin` — сбрасывает администратора (только из текущего чата администратора).

Состояние администратора хранится в Netlify Blobs. Другую базу данных настраивать не нужно.

## Установка

1. Создайте репозиторий GitHub и загрузите **содержимое этой папки**, не ZIP-файл.
2. В Netlify выберите **Add new site → Import an existing project → GitHub**, укажите этот репозиторий и нажмите Deploy. Команды сборки указывать не нужно.
3. В настройках сайта Netlify добавьте одну переменную окружения:
   - `BOT_TOKEN` — токен, полученный у `@BotFather`.
   После добавления переменной запустите новый deploy.
4. Откройте в браузере адрес вашего сайта с окончанием `/.netlify/functions/setup`. Страница вернёт `ok: true` и ссылку на Telegram-бота.
5. Сразу откройте бота со своего аккаунта и отправьте `/start`, затем `/admin`. Бот подтвердит, что этот чат назначен администратором.
6. Только после этого распространяйте ссылку на бота среди клиентов.

## Важно

- Команду `/admin` нужно отправить **первой, до публикации ссылки клиентам**. Первый чат, который выполнит эту команду, станет получателем заявок.
- Не публикуйте токен бота в GitHub. Он хранится только в переменных окружения Netlify.
- Для смены администратора текущий администратор пишет `/resetadmin`, затем из нового чата отправляет `/admin`.
